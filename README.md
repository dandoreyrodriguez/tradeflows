# Project TradeFlows  

**This is the current back-end of the TradeFlows project, a platform visualising the structure of global trade.**

Project TradeFlows is a platform which visualises global trade. Its goal is to bring to life the decisions of importers and exporters by applying economic theory to granular trade data. 

The pipeline uses **UN Comtrade** data, via their `comtradeapicall` python package. For US tariff data, we use the USITC HTSUS REST API. The next iteration of this project will add other national tariff schedules.
